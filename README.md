# IQC · ATLAS

> *An atlas of WorldQuant Brain alpha factors mapped by realized PnL correlation.*

A cartographic interface to **6,089 alpha factors** simulated on the USA TOP3000
universe at delay 1, decay 4, SUBINDUSTRY neutralization, truncation 0.08,
**backfill 252**. All similarity is computed **100% on realized PnL** (cross-sectional
demeaned Pearson on the daily PnL series) — text embeddings are no longer used in the
similarity basis.

## What you see

| Plate | View | Description |
|-------|------|-------------|
| I | **Graph** | WebGL force-directed network. Edges = \|corr\| above threshold. Click a node to reveal its *constellation* (top neighbors) in the right panel. |
| II | **Map** | UMAP 2D embedding of the same correlation distance. |
| III | **Heatmap** | Cluster × cluster mean \|r\|. Toggle to a subset matrix when fewer than 500 fields are selected. |
| IV | **Groups** | Cluster cards at four edge thresholds (≥ 0.10 / 0.25 / 0.35 / 0.50). |

## Detail panel

Selecting any field opens a slide-in plate with:

- Sharpe, fitness, turnover, returns, drawdown, long/short counts
- **Cumulative PnL** sparkline (per-field lazy-load)
- The exact FASTEXPR (`rank(ts_backfill(field, 252))` or with `vec_avg` wrap)
- Top-10 constellation neighbors with their correlation coefficients

## Local

The site is fully static. The pre-built data lives under `assets/data/`.

```sh
# any static server
python3 -m http.server 8000
# → http://localhost:8000
```

## Data pipeline

Generated by [IQCRAG](https://github.com/superjin1218/IQCRAG) scripts
`11_build_pnl_corr_v2.py` → `12_cluster_v2.py` → `13_umap_v2.py` → `14_build_site_assets_v2.py`,
which writes directly into `IQC-SITE/assets/data/`.

## Aesthetic

Editorial cartography in dark mode — Fraunces display, Geist body, JetBrains Mono for all
data. No rounded corners. Thin ruled borders. Single bold accent (copper). Subtle grain
overlay. Inspired by 19th-century geographical atlases and Bridgewater internal research
tooling.
